bird.ips     : Moves the code module for the bird enemies (crow and vulture) to slot 11 (baddie7).
croc.ips     : Moves the code module for the crocodile enemy to slot 11 (baddie7).
lizard.ips   : Moves the code module for the lizard man enemy to slot 10 (baddie6).
nofmv.ips    : Disables playing FMV's (no longer applied: the Eidos logo FMV plays again, see patch.sh)
initload.ips : Disables showing the "LOADING"-screen (no longer applied: PIX\INITLOAD.RAW is shown again, per language).
secrets.ips  : Adjusts the levels' number of secrets.
adventur.ips : Makes the "Select Next Adventure"-globe not trigger after level 4.
savename.ips : Changes the savegame's name to "Tomb Raider: The Lost Artifact"
strsofar.ips : Removes the "Story so far..." option from the Load-Game-screen.
sky.ips      : Changes the colour of the sky to fit the new levels.
loadbar.ips  : Make the loading bar 256 pixels wide
reunionlava.ips : Fixes Reunion's lava/acid incorrectly triggering the Rapids-level drowning reaction (level-slot collision).
credits10.ips : Shows ten end credit pictures (CREDIT01-10.RAW): 9 -> 10, Japanese 13 -> 10; Japanese also 150 -> 210 frames per picture like the other NTSC discs (they were timed for 13 pictures).
reunionview.ips : Shorter draw distance for the rooms in Highland Fling (14 blocks) and Reunion (12 blocks, fog from 12 blocks, 4 blocks long) only, so they run smoother; objects keep the original 20 blocks.
roomguard.ips : Draws a room piece only while the GPU primitive buffer has room for it, so very busy views no longer overrun the buffer (broken polygons, hanging picture, crash at the next loading screen).
duckroll.ips : Forward roll out of the crouch: Sprint while crouching starts the roll (state 72) when Lara's hands are free (no gun drawn), which ends in the crouch; the roll gets the crouch's collision.
newgameplus.ips : New Game+ as in Tomb Raider II: finishing the game switches on the bonus mode. Limited ammunition (DE 10, Uzis 80, shotgun 12, MP5 80, rockets 4, harpoon 24, grenades 6, 2 flares, a small and a large medipack) used up as usual, the pistols in Lara's hands, one save crystal instead of 50, Lara takes twice the damage; the first level's normal start no longer keeps the shotgun.
pickup3d.ips : 3D pickups as in Tomb Raider IV. Takes 0xDE0 bytes (US executables: 0x1000) from the end of the level memory; the routines (and those of crawlflip.ips, crouchturn.ips, ngpfile.ips and ngpchoice.ips) are appended to the executable and copied there at start-up.
crawlflip.ips : Forward crawl exit: Jump at the edge of a crawlspace (crawl standstill 263/264, end of stopping 266/268, or the crouch with Duck held, remembered into the crawl) starts animation 313 (added to every level by tools/add_crawl_flip.py, to Lara's home by tools/psx_lara_anims.py); no two-handed gun in the roll and the flip. Picking up in the crawl: animation 292 (poses by tools/add_crawl_pickup.py) instead of the crouch, the camera stays behind Lara.
crouchturn.ips : Turning on the spot in the crouch, as in Tomb Raider IV: Left/Right while crouched (Duck held, or the ceiling too low to stand up) plays animation 314/315 (added by tools/add_crouch_turn.py and tools/psx_lara_anims.py) and turns Lara 1.5 degrees per frame; the crouch also calls the crawl exit of crawlflip.ips.
ngpfile.ips : The New Game+ has a savegame of its own: with the bonus mode on, the memory card file name ends in P instead of G.
ngpchoice.ips : New Game+ choice as in the Remastered games: unlocked by the New Game+ savegame (the save after the end credits), "New Game" asks for the game mode (with the level select before the level list), "Load Game" asks which savegame when both exist, "Create/Overwrite New Game+" in the save dialog and a + in the card title. The end statistics' save offers a normal game as the normal savegame (every level reached) and then as the New Game+ (the first level only), a New Game+ once (its levels kept), always starting in the first level (not the bonus level 20 after all secrets); a normal start gives the later levels the first level's start equipment; at a level start in the New Game+ Lara keeps what she has; Lara's home always starts normally, ends the New Game+ and stops the last level's music. ngpchoice_<language>.ips: the same for the US executable of a European NTSC disc, in that language.
savename_<language>.ips : (US executables only) the savegame title of a European NTSC disc in its language (tools/make_ntsc_savename_ips.py).
lotslots4.ips : 4 instead of 5 creature slots with pathfinding, so Highland Fling has enough level memory for all of them (with 5 the last one got none and the game crashed when it was used).
japanweapons.ips : Optional: Lara's weapons do twice the damage, as on the Japanese and Asian Disc 1.
bloodred.ips : Optional: red blood in every language (the German versions show purple blood otherwise).
bloodpurple.ips : Optional: purple blood in every language, as in the German versions.
